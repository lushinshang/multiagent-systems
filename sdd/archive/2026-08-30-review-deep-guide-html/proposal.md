# 提案：呼叫 claude -p 結合總編輯與 deep-guide-html 規範審查並修訂 index.html

## 為什麼做

目前的導讀網頁 `index.html` 雖已具備基礎架構與繁體中文圖表，但為了達到出版級品質，需結合 `editor-in-chief`（總編輯審查）與 `deep-guide` 的專業標準。透過呼叫外部 `claude -p` 執行客觀、嚴苛的資深編輯審查，對照原文 `multiagent-systems.md`，去除 AI 撰寫痕跡（如過度工整的排比、抽象名詞、機械轉折詞），確保論文事實與數據無任何扭曲遺漏，並提升文字可讀性與排版張力。

## 要改什麼

- **總編輯審稿（呼叫 claude -p）**：
  - 檢視 `index.html` 與原文 `multiagent-systems.md` 的論述對齊度與事實準確性。
  - 診斷「AI 腔調」訊號（工整排比句尾、抽象空洞詞彙、機械轉折詞、對稱段落）。
- **內文潤飾與去 AI 感**：
  - 以最小改動原則，將生硬段落改為富有人手感、節奏起伏的流暢口語散文。
  - 精確呈現論文中的具體細節（例如：45 隻代理漏洞掃描對比、18/30 代理命名同名分支、Bertrand 價格卡特爾、隱藏特徵 17%~36% 慘況、Turf war 殺死競賽進程與 Rust 指標挑選）。
- **網頁排版與體驗優化**：
  - 檢查 HTML 標題層級、引用區塊、圖表說明之呼吸感與字體渲染。
  - 確保 Lightbox 點擊放大與手機/桌面響應式閱讀無任何瑕疵。
- **產出審查報告**：條列「審查前 vs 審查後」的核心修訂重點與理由。
