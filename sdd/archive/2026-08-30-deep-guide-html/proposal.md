# 提案：將多代理系統論文轉換為繁體中文深度導讀 HTML（index.html）

## 為什麼做

Anthropic 的多代理系統研究論文（`multiagent-systems.md`）包含豐富的實驗洞見（如協同與平行掃描、低變異性帶來的同質化風險、脆弱的認識論防禦、地盤爭奪戰與惡意程式升級等）。為了讓讀者能以最流暢的節奏吸收核心架構與底層洞察，需結合 `deep-guide`（深度導讀敘事技法）與 `md_to_html`（獨立發布級 HTML 排版標準），將素材轉化為一份具備專業導讀視角、完整嵌入繁體中文圖表、支援燈箱放大與響應式閱讀體驗的 `index.html` 網頁。

## 要改什麼

- **深度導讀內容編寫（deep-guide）**：
  - 根據論文內容進行思維維度路由，以生活化直覺映射、痛點錨定、機制解構、深層真相與落地價值展開敘事。
  - 去除 AI 模板痕跡，使用道地台灣繁體中文（台灣用語）。
  - 將 7 張已完成中文化的圖表有機融入各段落論述。
- **網頁排版與互動建置（md_to_html）**：
  - 產出獨立無相依性的 `index.html`。
  - 排版標準：護眼柔和米白背景（`#f9f7f4`）、Notion 式閱讀欄寬（本文 `720px`）、台灣繁體中文字體堆疊（PingFang TC / Noto Sans TC）。
  - 互動功能：加入章節快速導覽列（Sticky Nav）與圖表點擊放大燈箱（Lightbox）。
- **語法與排版驗收**：驗證 HTML 語法完整性、圖表連結與行動端/桌面端視覺效果。
